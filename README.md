# Шаблон лабораторної роботи №1

Курс «Основи FE-технологій». Тема: «Мова гіпертекстової розмітки сайту HTML-5».

## Як заповнити

1. Розпакуйте архів і відкрийте папку `lab1-template` у VS Code.
2. У `index.html` замініть усі написи у квадратних дужках своїми даними, зокрема в `title` та метатегах `keywords` і `description`. У заголовку вкладки мають бути прізвище та ініціали, група, номер лабораторної і номер варіанта.
3. Заповніть ПІБ, дату й місце народження та інформацію про школу й університет.
4. Вкажіть щонайменше три хобі та три улюблені книги або фільми.
5. Напишіть абзац про улюблене місто, в якому ви бували.
6. Покладіть фото міста в папку `images`, наприклад `city.jpg`. У тегу `img` змініть `src` на `images/city.jpg`, а `alt` — на опис зображення. Враховуйте регістр літер у назві файлу.
7. У тегу `a` замініть `https://example.com/` на адресу сайту обраного міста. Після цього натискання на фото відкриватиме сайт міста.
8. Збережіть файл та відкрийте `index.html` у браузері подвійним натисканням. Після змін оновлюйте сторінку.

Шаблон використовує HTML5 без бібліотек, JavaScript та CSS. SVG у папці `images` є лише заглушкою: перед здачею замініть її справжнім фото.

## Git та публікація

Встановіть Git із https://git-scm.com/ і створіть порожній репозиторій на GitHub. У терміналі папки проєкту виконайте, підставивши власну адресу репозиторію:

```bash
git init
git add .
git commit -m "Add laboratory work 1"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

Для публікації через GitHub Pages виберіть у налаштуваннях репозиторію розділ Pages, джерело Deploy from a branch, гілку `main` та папку `/ (root)`. Файл `index.html` повинен лежати в корені репозиторію. Якщо інтерфейс відрізняється, скористайтеся документацією GitHub Pages: https://docs.github.com/en/pages .

## Перевірка та звіт

Після заповнення перевірте HTML на https://validator.w3.org/ через завантаження `index.html` або за адресою опублікованої сторінки. Перевірте також, що фото відображається й натискання відкриває сайт міста.

До звіту додайте результати валідації та пояснення знайдених недоліків, скріншот сторінки, посилання на репозиторій і створений сайт. Зазначте використані інструменти та спосіб локального запуску. Заповнений шаблон сам по собі не замінює роботу з Git, публікацію та валідацію.
